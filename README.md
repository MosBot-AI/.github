# MosBot AI organization profile

This repository contains the public [MosBot AI organization homepage](https://github.com/MosBot-AI).

- [`profile/README.md`](profile/README.md): English organization profile.
- [`profile/README-zh.md`](profile/README-zh.md): Simplified Chinese companion.
- [`profile/assets/`](profile/assets/): Original, self-contained SVG artwork with light and dark variants.

The profile uses native GitHub Markdown and supported HTML. Essential information stays in selectable text, with a single-column layout for small screens. The artwork uses no remote fonts, tracking images, scripts, or third-party badge services.

When updating the profile, keep both languages aligned, verify all links, and distinguish current public capabilities from the roadmap. The public project README is the source of truth for development status.
